# House Price Prediction using Linear Regression

This project predicts house prices using Linear Regression based on house features such as area, bedrooms, and bathrooms.

## Dataset
Housing.csv

- Total Records: 545
- Total Features: 13

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Features Used
- Area
- Bedrooms
- Bathrooms

## Target Variable
- Price

## Project Workflow
1. Load the dataset
2. Perform data exploration
3. Select features and target variable
4. Split data into training and testing sets
5. Train Linear Regression model
6. Make predictions
7. Evaluate model performance
8. Visualize results

## Model Performance

| Metric | Value |
|----------|----------|
| MAE | 1265275.67 |
| RMSE | 1658324.60 |
| R² Score | 0.456 |

## Visualizations
- Actual vs Predicted Prices
- Correlation Heatmap
- Area vs Price Scatter Plot

- Bathrooms = 2

## Conclusion
A Linear Regression model was successfully developed to predict house prices. The model demonstrates the relationship between house features and price and provides reasonable predictions.
